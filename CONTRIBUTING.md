# Contributing to BEM FILKOM UNIDA

Thanks for your interest in contributing! We keep things simple here.

## Getting Started

1. **Fork & Clone**
   ```bash
   git clone https://github.com/aliimndev/bem-filkom-unida.git
   cd bem-filkom-unida
   ```

2. **Install Dependencies**
   ```bash
   bun install
   ```

3. **Run Development Server**
   ```bash
   bun dev
   ```

## Workflow

1. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **Make Changes**
   - Use **TypeScript** for all new code.
   - Use **Tailwind CSS** for styling.
   - Ensure the build passes (`bun run build`).

3. **Commit & Push**
   ```bash
   git add .
   git commit -m "feat: description of changes"
   git push origin feature/your-feature-name
   ```

4. **Open a Pull Request**
   - Go to GitHub and open a PR to the `main` branch.
   - Describe your changes clearly.

## Code Style

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Formatter:** Prettier (run `bun run format` if available, or rely on editor settings)

Happy coding! 🚀
